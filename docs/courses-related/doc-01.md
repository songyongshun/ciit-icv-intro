# 相关文献

- 2026，物理学报，[《量子电池的研究进展》](https://wulixb.iphy.ac.cn/cn/article/doi/10.7498/aps.75.20251507)
  - review, 综述了量子电池的研究进展，介绍了量子电池的基本概念、模型和性能指标，并讨论了量子电池的实现方法和应用前景。
  - 理论背景和方法部分，写的很好.
    - 2013年, Alicki和Fannes首次提出了量子电池的概念, 并将其定义为一个d维非简并的能级系统 ($ϵ_i<ϵ_{i+1}$)。
    - 2020年, Alimuddin等对被动态的几何状态空间进行了表征, 并引入了一种基于量子电池充电能力的操作区分方法. 
    - 2021年, Kamin等研究发现从量子系统中提取遍历熵时会损失部分能量, 并通过被动态的可用能(exergy)予以量化. 
    - 2024年, Yang等采用双光子态技术, 对量子电池容量及其他量子特性之间的关系进行了实验验证。
    - 2025年, Sarkar等发现在能量提取过程中, 无论采用幺正操作、完全正定保迹映射(CPTP映射), 还是包含物理可实现非CPTP映射的任意量子映射, 遍历熵的涨落均与电池维度成反比.
    - 2025年, Wang等研究了**局域冯·诺依曼测量**对三体量子系统中量子电池容量的影响, 提出两种基于测量的协议, 并引入最优局域投影算子的概念.
