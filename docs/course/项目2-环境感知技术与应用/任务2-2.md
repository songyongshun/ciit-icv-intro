## 一、知识链接

### 1. 智能网联汽车如何识别道路？

#### （1）道路识别的定义

道路识别就是把真实的道路通过环境感知传感器转换成汽车能认识的道路，供智能网联（自动驾驶）汽车行驶；或通过视觉传感器识别出车道线，提供车辆在当前车道中的位置，提高行驶安全性。

道路识别的作用：

- ① 提取车道的几何结构，如车道的宽度、车道线的曲率等；
- ② 确定车辆在车道中的位置和方向；
- ③ 提取车辆可行驶的区域。

#### （2）道路识别的分类

- 根据**道路构成特点**：分为**结构化道路**和**非结构化道路**。
- 根据**所用传感器类型**：分为视觉传感器的道路识别方法和雷达的道路识别方法两种类型。
  - 视觉传感器的道路识别方法：通过视觉传感器采集道路图像，并通过控制单元（ECU）处理图像、识别车道线。
  - 雷达的道路识别方法：通过雷达采集道路信息，并通过 ECU 处理信息、识别车道线。
  - 实际应用中主要采用**视觉传感器**的识别方法。

#### （3）道路图像的特点

复杂的道路环境和气候（阴影、强弱光照、雨天、弯道等）都会影响道路识别。

#### （4）道路识别的流程与方法

**识别流程**：原始图像采集 → 图像灰度化 → 图像滤波 → 图像二值化 → 车道线提取

**识别方法**：
1. 区域分割的识别方法；
2. 道路特征的识别方法；
3. 道路模型的识别方法；
4. 道路特征与模型相结合的识别方法。

### 2. 智能网联汽车如何识别前方车辆？

- **车辆特征的识别方法**：根据车辆的颜色、轮廓、对称性等特征将车辆与背景区别开。
- **车辆模型的识别方法**：根据前方运动车辆的参数建立二维或三维模型，再利用搜索程序匹配查找前方车辆。
- 采用**多传感器融合技术**是未来车辆识别技术的发展方向，目前主要有**视觉传感器与激光雷达的融合**，以及**视觉传感器与毫米波雷达的融合**。

### 3. 智能网联汽车如何识别行人？

#### （1）行人识别的定义

行人识别是采用安装在车辆前方的视觉传感器采集前方场景的图像信息，通过分析处理实现行人的识别。行人识别的目的是及时准确地检测出车辆前方的行人，并根据不同危险级别提供不同预警提示。

#### （2）行人识别的类型

- **可见光行人检测**：采用普通光学摄像头，符合人的正常视觉习惯、成本低，但受光照限制，只能应用在白天。
- **红外行人检测**：采用红外热成像摄像头，利用物体发出的热红外线成像，不依赖光照，具有很好的夜视功能，克服了可见光在夜间或阴雨天无法使用的问题。

#### （3）行人识别系统的组成

行人识别系统由**预处理、分类检测和决策报警**三部分组成。

#### （4）行人识别的方法

主要包括根据**特征分类**、根据**模型**、根据**运动特性**、根据**形状模型**等识别方法。

### 4. 智能网联汽车如何识别交通标志？

道路交通标志向驾驶员提供引导和约束信息，是保障行车安全的前提。交通标志具有鲜明的色彩特征，颜色是分割检测的重要信息。选择合适的颜色空间加以分析提取，有助于提高识别实时性和准确性。

**识别系统**：交通标志识别系统首先使用视觉传感器（车载摄像头）获取目标图像，然后进行图像分割和特征提取，通过与交通标志标准特征库比对进行识别。识别结果也可以与其他智能网联汽车共享。

**识别流程**：原始图像采集 → 图像预处理 → 图像分割检测 → 图像特征提取 → 交通标志识别

**识别方法**：
1. 根据颜色特征的识别；
2. 根据形状特征的识别；
3. 根据显著性的识别；
4. 根据特征提取和机器学习的识别。

### 5. 智能网联汽车如何识别交通信号灯？

不同国家和地区交通信号灯式样不完全相同。我国交通信号灯在颜色、安装方法和功能上具有典型特征。

**识别系统**：包括**检测**和**识别**两个环节。

- **检测环节**：通过车载摄像机从复杂环境中获取图像，根据颜色、几何特征等准确定位交通信号灯，获取候选区域。
- **识别环节**：对候选区域进行分析及特征提取，进行分类识别。

**识别流程**：原始图像采集 → 图像灰度化 → 直方图均衡化 → 图像二值化 → 信号灯识别

**识别方法**：
1. 根据颜色特征：选取色彩空间，对红、黄、绿 3 种颜色进行识别；
2. 根据形状特征：利用交通信号灯与其支撑物之间的几何信息进行识别；
3. 可将颜色特征和形状特征结合，减少识别偏差。
