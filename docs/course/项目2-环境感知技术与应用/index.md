# 项目二　智能网联汽车环境感知技术与应用

环境感知是智能网联汽车实现自动驾驶的第一步，也是最关键的一环。本项目将学习环境感知系统的组成、各类环境感知传感器（视觉传感器、雷达），以及道路、车辆、行人、交通标志与交通信号的识别。

## 项目目标

1. 理解环境感知技术的定义、系统组成和环境感知器的类型与配置。
2. 掌握视觉传感器（单目、双目、多目、红外夜视）的原理与应用。
3. 掌握超声波雷达、毫米波雷达、激光雷达的原理、优缺点与应用。
4. 了解智能网联汽车如何识别道路、前方车辆、行人、交通标志与交通信号灯。
