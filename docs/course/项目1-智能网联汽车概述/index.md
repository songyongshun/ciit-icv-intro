# 项目一　智能网联汽车概述

智能网联汽车是车联网与智能汽车驾驶技术相结合的产物，是智能交通系统的核心组成部分。本项目从整体上认识智能网联汽车，为后续各项目的深入学习奠定基础。

## 项目目标

1. 理解智能网联汽车的定义、分级方法（智能化分级与网联化分级）。
2. 认识智能网联汽车的环境感知层、智能决策层、控制和执行层等结构组成。
3. 了解智能网联汽车的关键技术、与传统汽车的区别以及标准体系。
4. 了解国内外无人驾驶汽车技术的发展历程、现状与发展趋势。
