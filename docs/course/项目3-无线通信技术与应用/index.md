# 项目三　智能网联汽车无线通信技术与应用

无线通信技术是智能网联汽车实现 V2X 通信的基础。本项目学习无线通信基础、V2X 通信技术、移动通信技术（尤其是 5G）以及物联网无线通信技术。

## 项目目标

1. 理解无线通信的概念、分类与 V2X 通信技术。
2. 了解移动通信技术（尤其是 5G）及其在 V2X 中的应用。
3. 掌握短距离无线通信技术和低功耗广域网（LPWAN）通信技术及其应用。
