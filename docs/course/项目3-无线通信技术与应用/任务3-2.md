## 一、知识链接

### 1. 什么是物联网？

物联网（Internet of Things，IoT）指**物物相连的互联网**。按照国际电信联盟（ITU）的定义，物联网解决**物品与物品（T2T）、人与物品（H2T）、人与人（H2H）**之间的互联。中国物联网校企联盟将物联网定义为几乎所有技术与计算机、互联网技术的结合，实现物体与物体之间、环境以及状态信息实时的共享以及智能化的收集、传递、处理、执行。广义上说，当下涉及信息技术的应用，都可以纳入物联网的范畴。

物联网“物与物”之间的信息交换依赖无线通信技术。

### 2. 物联网无线通信技术的类型

物联网无线通信技术将车辆、家用电器、公共设施以及各种电子产品、软件分别连接到互联网中。应用于物联网的无线通信技术主要分为两类：

- **短距离无线通信技术**：主要包括 Wi-Fi、蓝牙、射频识别（RFID）以及 Zigbee 等。
- **低功耗广域网通信技术（LPWAN）**：专为低带宽、低功耗、远距离、大量连接的物联网应用而设计。

### 3. 短距离无线通信技术

#### （1）Wi-Fi 通信技术

Wi-Fi 是无线局域网络认证标准，又称 IEEE 802.11 标准，是全球无线局域网的通用标准。

- **优点**：无线电波覆盖范围较广、传输速率较高、无线数据传播模式。
- **缺点**：安全性较低、易受干扰、功耗较高、组网能力低。

#### （2）蓝牙通信技术

蓝牙是一种适用于**短距离范围内的无线通信标准**，由蓝牙技术联盟（Bluetooth SIG）制定，目前最新版本为蓝牙 5.2。

- **优点**：功耗低、低延时、较高的安全性、有效范围内可无视障碍物进行连接。
- **缺点**：传输距离较短、传输速率不高。

#### （3）射频识别（RFID）通信技术

通过无线电信号对目标物体进行自动识别以及数据信息的读取。RFID 通信由**电子标签、带天线的读写器和控制器（应用软件）**三部分构成。

- **技术特性**：超强抗干扰性；存储空间较高（最高可扩充至 1MB 以上）；可通过编程动态修改数据；使用寿命长；对障碍物穿透能力强；可设置密码、安全性高；可同时对多个产品快速扫描读取。
- **分类**：无源 RFID、有源 RFID 和半有源 RFID。

#### （4）Zigbee 通信技术

Zigbee 又称“紫蜂协议”，是一种小范围、低功耗、低速率、低成本的无线自组织网络技术，基于 IEEE 802.15.4 标准。应用于自动化领域和远程控制领域。Zigbee 网络节点按功能可分为**协调器、路由器和终端设备**。

### 4. 低功耗广域网（LPWAN）技术

LPWAN 技术具有**低带宽、低功耗、远距离、海量连接**的特点，分为两类：

- **未获授权频段下使用**的技术：如 **LoRa 通信技术**。
- **授权频段下使用**的技术：如 **NB-IoT 通信技术**。

#### （1）LoRa 通信技术

LoRa（Long Range）即远距离大范围无线通信，主要在 ISM 频段应用。LoRaWAN 是 LoRa 广域网标准，规范了 LoRa 技术在其他无线通信网络中的通信协议。

- **网络构成**：LoRa 终端设备、基站、应用服务器和云服务器。
- **优点**：远距离通信（最远可达 20km）、低功耗、多节点（网络节点可达十万级）。
- **缺点**：频段易受干扰、需重新建设网络信号塔和基站。

#### （2）NB-IoT 通信技术

NB-IoT（Narrow Band Internet of Things）即窄带物联网技术，内建于蜂窝网络，只消耗约 180kHz 的带宽，可直接部署于 GSM、UMTS 或 LTE 网络，降低部署成本、实现平滑升级。具有**广覆盖、低成本、低功耗、支持海量连接**的特点。

**应用架构**：由 NB-IoT 终端、NB-IoT 信息网络和 NB-IoT 人机交互系统三部分组成。

#### （3）LoRa 与 NB-IoT 参数对比

两者都是 LPWAN 技术，但 LoRa 工作在未授权频段、NB-IoT 工作在授权频段（蜂窝网络）。

### 5. 物联网无线通信技术在智能网联汽车上的应用

**（1）应用优势**：
1. 继承移动网络的全部优点；
2. 可根据硬件或需求采用多种技术组合应用；
3. 低功耗；
4. 覆盖范围广。

**（2）应用体现**：
- ① 行驶中遇到紧急情况时，通过蓝牙发出提示信息；
- ② 发生故障或事故时，通过 Wi-Fi 向服务器发送支援请求，或通过 Zigbee 向附近车辆发送支援请求；
- ③ 自动驾驶时，通过射频识别技术获取前方道路信息、控制行驶方向；
- ④ 通过 LoRa 和 NB-IoT 打造车与车、车与路、车与互联网的低功耗广域网络。

> 随着移动网络通信技术和物联网无线通信技术在汽车中的应用，智能网联汽车的 V2X 功能将全面实现，让汽车“无人驾驶”成为可能。

（1）物联网的无线通信技术主要分为两类，包括（ ）。
