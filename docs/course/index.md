# 智能网联汽车概论

智能网联汽车（Intelligent Connected Vehicle，ICV）是车联网与智能汽车驾驶技术相结合的产物，是本课程学习与研究的核心对象。本课程按照 **项目—任务** 的层级组织，共设 6 个项目、12 个任务。

## 学习方法

- 每个任务均按照 **“任务目标 → 知识链接 → 任务实施（工单） → 自我测试”** 的结构编排。
- 课程配套《工单试题》，可结合实训整车、台架、模型进行实践操作。
- 建议结合互联网资讯，主动查阅国内外智能网联汽车最新的政策、技术与产品动态。
