# 项目五　智能网联汽车高精度导航定位技术与应用

导航定位是智能网联汽车实现自动驾驶的关键环节，本项目学习导航定位技术、各类导航定位系统以及高精度地图的制作与应用。

## 项目目标

1. 了解导航定位技术及智能网联汽车导航定位系统的要求。
2. 掌握 GPS、DGPS、北斗（BDS）、惯性导航（INS）、激光雷达定位的原理与特点。
3. 了解高精度地图与普通导航地图的区别、制作过程与应用现状。
