# 项目六　智能网联汽车 ADAS 技术与应用

高级驾驶辅助系统（ADAS）是智能网联汽车的重点技术领域，本项目学习各类 ADAS 系统（ACC、FCW、LDW、LKA、盲区监测、疲劳预警、AEB、自动泊车等），以及自动驾驶的路径规划与决策控制。

## 项目目标

1. 掌握 ADAS 的定义、类型及各典型系统（ACC、FCW、LDW、LKA、BSD、DFMS、AEB、APA）。
2. 理解自动驾驶的核心技术组成与感知、路径规划、行为决策、车辆控制。
