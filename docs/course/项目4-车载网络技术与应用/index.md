# 项目四　智能网联汽车车载网络技术与应用

车载网络是智能网联汽车各电子控制单元互联的基础，本项目学习车载总线系统、CAN/LIN/MOST/FlexRay 总线，以及车载移动互联网、车载以太网与车载自组织网络。

## 项目目标

1. 掌握车载总线系统的概述、分类与基本概念。
2. 掌握 CAN、LIN、MOST、FlexRay 总线的组成、原理与应用。
3. 了解车载总线网络的故障诊断与维修。
4. 了解车载移动互联网、车载以太网与车载自组织网络。
